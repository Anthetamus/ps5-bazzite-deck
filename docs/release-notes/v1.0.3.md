## What's new
- **Bluetooth works** (DualSense and other controllers): the PS5 Bluetooth chip is now set up correctly.

## Known issues
- Wi-Fi/Ethernet or Switch to Desktop can randomly stop working after a reboot. Fixed in v1.0.5 (one-line fix in the v1.0.5 notes).
- Switching from 4K down to a lower resolution can give "no signal". Fixed in v1.0.6.
- 1440p picture shifted on FLAVA3 consoles. Fixed in v1.0.7.
