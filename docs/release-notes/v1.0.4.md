## What's new
- **Wi-Fi:** joining networks from the settings and the first-boot "connect to the internet" step work reliably; Wi-Fi driver with the latest upstream fixes.
- **HDMI audio** more stable.
- **Fan control** fix (rmux's latest PS5 patches).
- **PS5 Slim / MediaTek Wi-Fi and Bluetooth** drivers included. One image for all models.
- Boot: removed an unused display entry from `cmdline.txt` that logged errors on every boot.

## Known issues
- Wi-Fi/Ethernet or Switch to Desktop can randomly stop working after a reboot. Fixed in v1.0.5 (one-line fix in the v1.0.5 notes).
- Switching from 4K down to a lower resolution can give "no signal". Fixed in v1.0.6.
- 1440p picture shifted. Fixed in v1.0.7.
