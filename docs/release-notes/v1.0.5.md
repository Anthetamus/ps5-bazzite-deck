## What's new
- **Fix: Wi-Fi/Ethernet or Switch to Desktop randomly missing after a reboot.** A boot service was ordered in a loop; systemd broke the loop by skipping a different service each boot.
- PS5 Slim / MediaTek Wi-Fi confirmed working.

## Known issues
- Switching from 4K down to a lower resolution can give "no signal". Fixed in v1.0.6.
- 1440p picture shifted on FLAVA3 consoles. Fixed in v1.0.7.
