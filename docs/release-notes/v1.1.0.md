## What's new
- Based on rmux's latest PS5 kernel patches.
- **1440p120 always available** if your TV/monitor offers it (no `cmdline.txt` option needed anymore).
- **1440p60** is offered too when your TV/monitor lists 1440p only at 120 Hz.
- **Fix: squeezed, discoloured picture on some 4K TVs** (whole picture in the left half): the picture now falls back to 1080p. For 4K60, turn on the TV's enhanced HDMI mode for that port (Samsung: Input Signal Plus, LG: HDMI Ultra HD Deep Colour, Sony: Enhanced format).
- **All 40 GPU compute units instead of 36**, on by default. If games crash, freeze or show glitches, change `amdgpu.ps5_cu_unlock=3` to `amdgpu.ps5_cu_unlock=0` in `cmdline.txt`.
