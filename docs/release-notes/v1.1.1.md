## What's new
- **The 40-CU unlock is opt-in again.** On some consoles the 4 extra GPU compute units cause green dots and other artifacts, a purple tint or crashes; that's the silicon lottery, the units were switched off at the factory for a reason. v1.1.1 runs with the normal 36 by default.
- Want to try 40? In a terminal or over SSH, then reboot:
  ```
  sudo sed -i -e 's/amdgpu\.ps5_cu_unlock=[0-9]*/amdgpu.ps5_cu_unlock=3/' -e '/ps5_cu_unlock/!s/[[:space:]]*$/ amdgpu.ps5_cu_unlock=3/' /efi/cmdline.txt && sudo cat /efi/cmdline.txt
  ```
  `dmesg | grep active_cu_number` then shows `40`. Your setting stays across in-place updates from now on.
- Otherwise the same as v1.1.0 (same kernel and drivers).
