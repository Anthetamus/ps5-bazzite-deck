## What's new
- **Fix: rainbow / "disco" colours.** Some TVs announce deep colour, and the PS5 then sent 10 or 12 bits per colour, which the PS5's HDMI chip shows as rainbow contours (and on some TVs a picture that keeps dropping out). The output is now always 8 bits per colour.
- **Fix: "timing issue" or no picture after switching displays** (e.g. capture card to monitor).
- **Fix: black screen / link training errors at boot** on some setups.
- **Fix: 1440p shifted to the left** with some displays and capture cards (e.g. Elgato 4K X).
