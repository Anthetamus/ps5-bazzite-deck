## What's new
- **Fix: 1440p picture a few lines too high** (the top edge cut off a little), e.g. with LG TVs at 1440p120. The PS5's HDMI chip expects the sync signals of the standard 1440p timing and moves the picture when a display uses the other vertical polarity; 1440p now always gets the standard one.
- **Updating is one command now**, for this and every future version (see below and the README).
- Everything else is the same as v1.3.0.

## Known issues
- On some setups the picture stays black at 4K60 on some boots. If that happens to you, add ` hdmi.log_notify=1` to `cmdline.txt`, and after a black boot send `sudo dmesg | grep -i -e notify -e setup` in Discord.
