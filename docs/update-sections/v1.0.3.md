## Updating from v1.0.2 (no reflash)
Only Bluetooth changed. On the PS5 (desktop → Konsole, password `ps5`):
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.0.3/btusb.ko && sudo cp btusb.ko /usr/lib/modules/$(uname -r)/kernel/drivers/bluetooth/btusb.ko && sudo depmod -a && sudo reboot
```
**Or update straight to the latest version in place:** see the [v1.0.6 release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v1.0.6) or [docs/updating.md](https://github.com/VivaLaVent/ps5-bazzite-deck/blob/main/docs/updating.md).
