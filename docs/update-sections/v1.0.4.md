## Updating from v1.0.3
v1.0.4 can't be installed on top of v1.0.3 on its own (new kernel and drivers). Either reflash, or update straight to the latest version in place, which includes everything since v1.0.4.

**Or update straight to the latest version in place:** `bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh)` (see the [latest release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/latest)) or [docs/updating.md](https://github.com/VivaLaVent/ps5-bazzite-deck/blob/main/docs/updating.md).
