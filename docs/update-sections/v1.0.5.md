## Updating from v1.0.4 (no reflash)
v1.0.5 is v1.0.4 plus one boot fix. On the PS5 (in a terminal, over SSH, or Ctrl+Alt+F2; password `ps5`), run this; it reboots:
```
sudo mkdir -p /etc/systemd/system/ps5-stage-firmware.service.d && printf '[Unit]\nDefaultDependencies=no\nConflicts=shutdown.target\nBefore=shutdown.target\n' | sudo tee /etc/systemd/system/ps5-stage-firmware.service.d/10-no-default-deps.conf >/dev/null && sudo systemctl daemon-reload && sudo reboot
```
After the reboot, `journalctl -b --no-pager | grep -c "ordering cycle"` should print `0`.

**Or update straight to the latest version in place:** see the [v1.1.0 release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v1.1.0) or [docs/updating.md](https://github.com/VivaLaVent/ps5-bazzite-deck/blob/main/docs/updating.md).
