## Updating from v1.0.3, v1.0.4 or v1.0.5 (no reflash)
One update bundle brings any of these to v1.0.6: kernel, drivers and settings. Your games, files and settings stay. On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.0.6/ps5-bazzite-deck-v1.0.6-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.0.6/ps5-bazzite-deck-v1.0.6-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.0.6-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.0.6-update.tar.xz && bash ps5-bazzite-deck-v1.0.6-update/update.sh
```
It checks the download, makes a backup, installs, and prints `DONE` plus an undo command. Then reboot and run the loader as usual. After the reboot, `cat /sys/module/hdmi/parameters/rearm` should print `Y`.

**From v1.0.2 or older:** reflash.

**Newer:** v1.0.7 has its own update bundle (from v1.0.3–v1.0.6), see the [v1.0.7 release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v1.0.7).
