## Updating from v1.0.3–v1.0.6 (no reflash)
One update bundle brings any of these to v1.0.7: kernel, drivers and settings. Your games, files and settings stay. On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.0.7/ps5-bazzite-deck-v1.0.7-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.0.7/ps5-bazzite-deck-v1.0.7-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.0.7-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.0.7-update.tar.xz && bash ps5-bazzite-deck-v1.0.7-update/update.sh
```
It checks the download, makes a backup, installs, and prints `DONE` plus an undo command. Then reboot and run the loader as usual. `cat /etc/ps5-bazzite-deck-version` then shows `v1.0.7`.

The in-place update doesn't switch SSH on; if you want it: `sudo systemctl enable --now sshd` (and change your password with `passwd`).
**From v1.0.2 or older:** reflash.
