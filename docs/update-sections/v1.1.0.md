## Updating from v1.0.3–v1.0.7 (no reflash)
One update bundle brings any of these to v1.1.0: kernel, drivers and settings. Your games, files and settings stay. On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.1.0/ps5-bazzite-deck-v1.1.0-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.1.0/ps5-bazzite-deck-v1.1.0-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.1.0-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.1.0-update.tar.xz && bash ps5-bazzite-deck-v1.1.0-update/update.sh
```
It checks the download, makes a backup, installs, and prints `DONE` plus an undo command. Then reboot and run the loader as usual. `cat /etc/ps5-bazzite-deck-version` then shows `v1.1.0`.

**From v1.0.2 or older:** reflash.

**Newer:** update to the latest version with one command: `bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh)` (see the [latest release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/latest)).
