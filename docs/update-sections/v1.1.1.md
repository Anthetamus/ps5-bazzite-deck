## Updating from v1.0.3–v1.1.0 (no reflash)
**On v1.1.0 and only want the fix?** This one command switches the 40-CU unlock off (in a terminal or over SSH), then reboot:
```
sudo sed -i 's/ *amdgpu\.ps5_cu_unlock=[0-9]*//' /efi/cmdline.txt && sudo cat /efi/cmdline.txt
```

**Or the full in-place update** (from any of v1.0.3–v1.1.0): kernel, drivers and settings. Your games, files and settings stay. With a network connection:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.1.1/ps5-bazzite-deck-v1.1.1-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.1.1/ps5-bazzite-deck-v1.1.1-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.1.1-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.1.1-update.tar.xz && bash ps5-bazzite-deck-v1.1.1-update/update.sh
```
It checks the download, makes a backup, installs, and prints `DONE` plus an undo command. Then reboot and run the loader as usual. `cat /etc/ps5-bazzite-deck-version` then shows `v1.1.1`. Coming from v1.1.0, it switches the 40-CU unlock off once; a setting you add afterwards is kept.

**From v1.0.2 or older:** reflash.

**Newer:** the latest update bundle (from v1.0.3 on) is in the [v1.3.0 release](https://github.com/VivaLaVent/ps5-bazzite-deck/releases/tag/v1.3.0).
