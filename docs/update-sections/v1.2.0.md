## Updating from v1.0.3–v1.1.1 (no reflash)
One update bundle brings any of these to v1.2.0: kernel, drivers and settings. Your games, files and settings stay. Also works if you're running one of the `hdmi-test` kernels. On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.2.0/ps5-bazzite-deck-v1.2.0-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.2.0/ps5-bazzite-deck-v1.2.0-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.2.0-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.2.0-update.tar.xz && bash ps5-bazzite-deck-v1.2.0-update/update.sh
```
It checks the download, makes a backup, installs, and prints `DONE` plus an undo command. Then reboot and run the loader as usual. `cat /etc/ps5-bazzite-deck-version` then shows `v1.2.0`. If you added ` hdmi.rearm=0` or ` amdgpu.force_1080p=1` to `cmdline.txt` as a workaround, you can remove them now.

**From v1.0.2 or older:** reflash.
