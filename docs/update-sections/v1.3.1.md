## Updating from v1.0.3–v1.3.0 (no reflash)
On the PS5 (in a terminal or over SSH, password `ps5`), with a network connection. This updates to the **latest** version (from now on, this one command always works):
```
bash <(curl -fsSL https://raw.githubusercontent.com/VivaLaVent/ps5-bazzite-deck/main/tools/update-latest.sh)
```
Or exactly this version:
```
cd ~ && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.3.1/ps5-bazzite-deck-v1.3.1-update.tar.xz && curl -LO https://github.com/VivaLaVent/ps5-bazzite-deck/releases/download/v1.3.1/ps5-bazzite-deck-v1.3.1-update.tar.xz.sha256 && sha256sum -c ps5-bazzite-deck-v1.3.1-update.tar.xz.sha256 && tar xJf ps5-bazzite-deck-v1.3.1-update.tar.xz && bash ps5-bazzite-deck-v1.3.1-update/update.sh
```
It checks the download, makes a backup, installs the new kernel, drivers and settings, and prints `DONE` plus an undo command. Your games, files and settings stay. Then reboot and run the loader as usual. Test kernels (`hdmi-test…`) are replaced too.

**From v1.0.2 or older:** reflash.
